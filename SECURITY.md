# Security

`spicefault` runs a circuit simulator on netlists you give it. Treat a netlist from an
untrusted source as you would a script: ngspice control blocks can run shell commands.

To report a vulnerability in the library itself, please use GitHub's
[private vulnerability reporting](https://github.com/telmomm/spicefault/security/advisories/new)
and do not open a public issue. You should receive an answer within two weeks.

Fixes are made on the latest released version.
